1. 变量、结构与字符串

解构赋值 (Destructuring)

// 对象解构 + 重命名 + 默认值
const { name: userName, age = 18 } = user;

// 嵌套解构
const { info: { id } } = response;

// 数组解构 (交换变量)
[a, b] = [b, a];

模板字符串 (Template Literals)

// 标签模板 (Tag Functions) - 常用作防 XSS 或多语言
function highlight(strings, ...values) {
  return strings[0] + `<span>` + values[0] + `</span>`;
}
const msg = highlight`Hello ${name}`;

2. Symbol 与 集合 (Map/Set)

Symbol: 独一无二的键

  • 用途： 作为对象属性名，防止属性被覆盖。
  • Symbol.for()： 全局注册表，如果键名相同则返回同一个 Symbol。
  • 隐藏性： for...in 遍历不到，需用 Object.getOwnPropertySymbols()。

Map vs Object

特性ObjectMap
键的类型String/Symbol任意类型 (包括对象)
顺序无序/复杂有序 (插入顺序)
大小需手动计算map.size

WeakMap & WeakSet (弱引用)

键必须是对象。其核心价值在于不计入垃圾回收 (GC) 引用计数。当键指向的对象在外部被销毁时，WeakMap 内部自动清理，防止内存泄漏。常用于 DOM 节点存储元数据。

3. 代理与反射 (Proxy & Reflect)

这是 Vue3 响应式的核心。它能拦截对象的所有操作（读取、赋值、删除、枚举等）。

const proxy = new Proxy(target, {
  get(target, key, receiver) {
    console.log(`读取了 ${key}`);
    return Reflect.get(target, key, receiver); // 配合 Reflect 保持 context
  },
  set(target, key, value) {
    if (key === 'age' && value > 100) throw Error();
    return Reflect.set(...arguments);
  }
});

4. Class 类与模块化

类的构成

class User {
  static type = 'HUMAN'; // 静态属性
  constructor(name) { this._name = name; }
  
  get name() { return this._name; } // getter
  sayHi() { console.log('Hi'); }   // 原型方法
}

class Student extends User {
  constructor(name, score) {
    super(name); // 必须先调用 super
    this.score = score;
  }
}

ES Module (ESM)

  • 命名导出： export const a = 1;
  • 默认导出： export default b;
  • 动态导入： import('./mod.js').then(...) 代码拆分关键

注：ESM 是编译时加载（静态），CommonJS 是运行时加载。
