JavaScript 核心基础全景图

1. 变量声明与数据类型

变量声明 (var / let / const)

  • var: 函数作用域，存在变量提升（Hoisting），允许重复声明。
  • let: 块级作用域，存在暂时性死区 (TDZ)，不能在声明前使用，不允许重复声明。
  • const: 块级作用域，声明时必须赋值，绑定后引用地址不可变（但若是对象，其内部属性可变）。

八大数据类型

基本类型 (栈内存): Number, String, Boolean, Undefined, Null, Symbol (唯一值), BigInt (大整数, 尾部加n)。

引用类型 (堆内存): Object (包含 Array, Function, Date 等)。

typeof 与 类型转换避坑

// typeof 的著名 Bug
typeof null === 'object'; // 历史遗留问题，null 在底层全为 0，而对象标签也是 000
typeof [] === 'object';   // 判断数组请用 Array.isArray()

// 隐式转换神坑
[] == ![]; // true。(1) ![] 变成 false (2) [] 变 "", false 变 0 (3) "" 变 0。 0 == 0
1 + "2";   // "12" (加号遇字符串则拼接)
1 - "2";   // -1 (减号强转数字计算)

2. 流程控制与函数机制

循环的本质区别

语法 作用域 核心特点
for...in 对象 (Object) 遍历对象的可枚举属性的键名(Key)，会遍历到原型链上的属性！
for...of 可迭代对象 (Iterable) ES6 新增，遍历对象的键值(Value)。适用于 Array, Map, Set, String，不适用于普通对象。

函数定义与箭头函数

// 1. 函数声明 (整体提升)
function foo() {}

// 2. 函数表达式 (仅变量提升，赋初值前调用会报错)
const bar = function() {};

// 3. 箭头函数 (Arrow Function) 的四大缺失：
// - 没有自己的 this (继承外层词法作用域)
// - 没有 arguments 对象 (请用剩余参数 ...args 替代)
// - 不能作为构造函数 (不能 new)
// - 没有 prototype 属性
const arrow = (...args) => { return args[0]; };

3. 作用域 (Scope) 与 闭包 (Closure)

作用域链： 当查找变量时，如果当前作用域没有，就会顺着外层词法作用域往上找，直到全局作用域。

闭包的本质： 闭包 = 函数 + 该函数声明时所处的词法环境。简单来说：内层函数引用了外层函数的变量，且内层函数被暴露到了外部。 
function createCounter() {
  let count = 0; // 私有变量，常驻内存不被销毁
  return function() {
    return ++count;
  };
}
const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2
// 闭包的应用场景：1. 数据私有化(封装)；2. 防抖节流；3. 柯里化 (Currying)。
// 注意：大量使用闭包会导致内存泄漏，需手动置为 null 释放。

4. this 指向与面向对象 (OOP)

this 的四种绑定规则

  1. 默认绑定： 独立函数调用 fn()，非严格模式指向 window，严格模式为 undefined。
  2. 隐式绑定： 对象调用 obj.fn()，this 指向 obj。
  3. 显式绑定： call / apply / bind。call/apply 立即执行（传参方式不同），bind 返回新函数。
  4. new 绑定： 指向新创建的实例对象。

原型与原型链 (Prototype Chain)

在 JS 中，万物皆对象。当你访问对象的一个属性时，如果自身没有，就会去它的 __proto__ (隐式原型) 上找，也就是其构造函数的 prototype (显式原型)。

// 核心公式，死记硬背：
实例对象.__proto__ === 构造函数.prototype

// 原型链的尽头：
Object.prototype.__proto__ === null

// 继承的终极方案：寄生组合式继承 (ES6 class extends 的底层原理)
function Parent(name) { this.name = name; }
function Child(name, age) {
  Parent.call(this, name); // 继承属性
  this.age = age;
}
Child.prototype = Object.create(Parent.prototype); // 继承方法
Child.prototype.constructor = Child; // 修复构造函数指向
