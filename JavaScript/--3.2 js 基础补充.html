JS 基础精读：遗漏考点补全

1. 运算符：你可能忽略的黑魔法

逻辑与高级运算符 (ES6+)

// 1. 逻辑空赋值 (??=) 和 空值合并 (??)
// 与 || 不同，?? 只在左侧为 null 或 undefined 时才返回右侧（0 和 "" 会被保留）
let count = 0;
let a = count || 10; // a = 10 (0 被当成 false 误判了)
let b = count ?? 10; // b = 0  (正确保留了 0)

// 2. 可选链 (Optional Chaining ?.)
const user = {};
console.log(user.address?.city); // undefined，不会抛出 Cannot read property 错误

位运算 (Bitwise) 面试骚操作

位运算直接操作二进制，速度极快，常用于算法或极客写法。

// 1. 双波浪号 (~~) 代替 Math.floor() 对于正数
console.log(~~3.14159); // 3

// 2. 按位异或 (^) 交换变量（不借助第三个变量）
let x = 1, y = 2;
x = x ^ y; y = x ^ y; x = x ^ y; // 现在 x=2, y=1

2. 流程中断：break vs continue vs return

关键字 作用域 核心行为
break 循环 (for/while)、switch 彻底砸碎当前循环，跳出整个循环体，执行循环外的后续代码。
continue 仅循环 (for/while) 仅跳过当前这一圈，直接进入下一次循环迭代。
return 仅函数体内 终止整个函数的执行，并可携带一个返回值给调用者。如果在循环里 return，不仅循环没了，函数也结束了。

3. 函数参数：arguments vs ...rest

过去我们用 arguments 收集未知数量的参数，但它有很多坑。现在推荐用剩余参数 ...args。

function oldWay() {
  console.log(typeof arguments); // 'object' (类数组，不是真数组！)
  // 必须借助 Array.from() 或 [].slice.call(arguments) 才能用 map/filter
}

function newWay(first, ...rest) {
  // rest 是一个真正的数组，直接可以使用数组的高阶方法
  return rest.map(i => i * 2);
}

// 默认参数 (Default Parameters) 的求值惰性：
function test(a = getDef()) {} // 只有当不传 a 时，才会执行 getDef() 函数

4. 继承方案演进史 (高频面试重灾区)

1. 原型链继承： Child.prototype = new Parent()
缺点：所有子类实例共享父类原型上的引用类型属性（一个改了，全变了），且无法向父类传参。

2. 构造函数继承： function Child() { Parent.call(this) }
缺点：只继承了实例属性，没继承原型链上的方法（方法都在构造函数里，无法复用）。

3. 组合继承： （原型链 + 构造函数）
缺点：父类构造函数被调用了两次，导致子类实例和原型上存在两份同名属性，浪费内存。

4. 完美方案：寄生组合式继承 (ES5 终极答案)

function Parent(name) { this.name = name; }
Parent.prototype.say = function() { console.log(this.name); };

function Child(name, age) {
  Parent.call(this, name); // 1. 借用构造函数继承实例属性
  this.age = age;
}

// 2. 创建父类原型的一个副本，避免二次调用父类构造函数
Child.prototype = Object.create(Parent.prototype);
// 3. 修复 constructor 指向
Child.prototype.constructor = Child;

5. ES6 class extends (语法糖)

ES6 的继承本质上就是寄生组合式继承的语法糖，但有一个核心区别：

  • ES5 是先创造子类的实例对象 this，然后再将父类的方法添加到 this 上（Parent.call(this)）。
  • ES6 是先将父类实例对象的属性和方法加到 this 上（所以必须先调用 super()），然后再用子类的构造函数修改 this。
