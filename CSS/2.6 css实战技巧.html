4. 渲染性能与魔法 (Performance & Houdini)

重绘 (Repaint): 改变外观（颜色、阴影），不影响布局。

回流 (Reflow): 改变几何结构（宽高、位置），代价昂贵，会触发重新计算布局。


CSS Houdini: CSS 引擎的低级 API，允许开发者通过 JS 直接接入浏览器的渲染流程（如自定义 Paint、Layout）。
