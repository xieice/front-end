5. 元素隐藏方案

[A] Hidden (none) [B] Hidden (visibility) [C]
  • display: none: 脱离文档流，不占空间，触发重排。
  • visibility: hidden: 占位，不触发重排，子元素可设 visible 显示。
  • opacity: 0: 占位，可响应点击事件。
