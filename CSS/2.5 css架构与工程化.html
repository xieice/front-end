CSS 工程化全景观

1. CSS 预处理器 (Preprocessors)

解决 CSS 无法嵌套、变量支持差、难以维护的问题。目前 Sass/SCSS 是行业标准。

// SCSS 演示 $primary: #42b983; @mixin flex-center { display: flex; justify-content: center; align-items: center; } .container { @include flex-center; .item { color: $primary; &:hover { opacity: 0.8; } } }

PostCSS： 严格来说它不是预处理器，而是一个插件转换平台（类似 CSS 的 Babel）。常用插件：Autoprefixer（自动补全前缀）、postcss-preset-env（使用未来特性）。

2. 命名规范与架构思想 (BEM / OOCSS / SMACSS)

BEM (Block Element Modifier)

解决命名冲突和权重问题。结构清晰，但类名可能较长。

.card { } // Block .card__title { } // Element (双下划线) .card--featured { } // Modifier (双连字符)

OOCSS & SMACSS

  • OOCSS: 面向对象 CSS。分离结构（width, margin）与皮肤（color, shadow）。
  • SMACSS: 将样式分为五类：Base, Layout, Module, State, Theme。

3. 作用域隔离 (CSS Modules & CSS-in-JS)

主要用于 React/Vue 组件开发，防止全局污染。

  • CSS Modules: 通过构建工具将类名哈希化，生成唯一的标识符。
  • CSS-in-JS (Styled-components): 在 JS 中写 CSS，支持动态逻辑。
// Styled-components 演示 const Button = styled.button` background: ${props => props.primary ? 'green' : 'gray'}; border-radius: 4px; `;

4. 现代原子化 (Tailwind CSS & UnoCSS)

实用主义极致： 不再起名字，直接在 HTML 中使用预设的类。配合 JIT（即时编译）引擎。

<div class="flex p-4 m-2 bg-green-500 rounded-lg shadow-xl hover:scale-105 transition"> Hello Tailwind! </div>

UnoCSS: 极致的原子化引擎，比 Tailwind 更快、更灵活，支持按需生成的正则表达式规则。

5. 设计令牌 (Design Tokens)

它是 UI 系统的“最小原子数据”。将颜色、间距、字体等抽象为与平台无关的变量（通常是 JSON）。

{ "color": { "brand": { "value": "#42b983" }, "error": { "value": "#ff4757" } }, "spacing": { "medium": { "value": "16px" } } }

意义： 保证 Web、iOS、Android 端样式的一致性。当设计师修改品牌色时，只需修改 JSON，所有端的 CSS 变量会自动更新。
