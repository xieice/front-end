6. 扩展：CSS 现代前沿 (Must Know)

  • Container Queries: @container。根据父容器大小而非视口改变样式，真正的组件化布局。
  • CSS Layers: @layer。显式控制样式优先级，解决权重冲突地狱。
  • Subgrid: 允许子元素继承父元素的网格行列定义，实现嵌套对齐。
  • Scroll-driven Animations: 无需 JS 即可根据滚动位置触发动画。
