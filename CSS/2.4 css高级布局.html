1. 格式化上下文 (Formatting Contexts)

BFC (Block Formatting Context) 是一个独立的渲染区域，内部子元素不会影响外部布局。

  • 触发方式： overflow 不为 visible、float 不为 none、display 为 inline-block/flex/grid、position 为 absolute/fixed。
  • 解决问题： 1. 清除浮动带来的父元素高度塌陷；2. 阻止外边距 (margin) 重叠；3. 制作自适应两栏布局。

4. 移动端适配方案

Viewport: 通过 <meta name="viewport" content="width=device-width, initial-scale=1"> 解决缩放问题。

Rem 适配 (过时但需了解): lib-flexible 动态修改 html 的 font-size。

5. CSS 容器查询 (@container)

打破媒体查询的局限性： 媒体查询监听的是浏览器视口宽度，而容器查询监听的是父元素的宽度。这使得组件在不同侧边栏或主栏中能自适应样式。
