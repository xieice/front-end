4. 性能优化与 Lottie

性能三法则：优先使用 Transform 和 Opacity，避免触发布局抖动。

Lottie 方案：设计稿导出 JSON，跨端一致。

💡 面试核心：动画性能优化 (Critical)

  • 渲染流水线： 动画触发 Layout (如 width) > Paint (如 color) > Composite (层合成)。
  • GPU 加速： 使用 transform (translate3d/scale/rotate) 和 opacity 仅触发 Composite，由 GPU 完成，不占主线程。
  • will-change： 慎用！仅对已知要频繁变化的元素使用，长期占用 GPU 内存会导致页面卡顿。
  • requestAnimationFrame： 如果用 JS 写动画，务必放弃 setInterval，使用 rAF 对齐屏幕刷新率 (60fps)。
